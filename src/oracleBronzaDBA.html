WindowsでLinuxを動かす

  1. Windows PCでLinuxを動かす も参考にWindowsでLinux(ubuntu)を使えるようにする
  2. 無料版Oracle Databaseダウンロードページ よりダウンロードURLをコピー
  3. LinuxコマンドでWEBからファイルをダウンロードする方法 を見てLinux環境に手順2でコピーした無料版Oracle Databaseをインストール

黒本ではLinuxで解説されるので、 Windows 11の標準機能でLinuxを動かす方法 を参照て自分のPCでもLinuxを使えるようにしました。 【2023年版】Ubuntuのインストール方法を解説~Windows PCでLinuxを動かす~ も参考にしました。 無料版のOracle Databaseを使いたかったのでOracle Databaseを無償で使う方法いろいろ を見てダウンロードURLをコピーしました。 LinuxコマンドでWEBからファイルをダウンロードする方法 を見てLinux環境に無料版Oracle Databaseをインストールしました。 インストールすると拡張子が「.rpm」となっています。これはzipファイルのようなものではありません。 【パッケージ】Linuxの「パッケージ」と「yum」と「rpm」について勉強したのでまとめてみた。 を見てまずはrpm拡張子について理解しましょう。 黒本ではLinuxで解説されますが、WindowsのPCにLinux（ubuntu）を入れて環境構築しようとしたところ大変過ぎました🙅 Windows PCの人はWindowsに入れることをお勧めします。
